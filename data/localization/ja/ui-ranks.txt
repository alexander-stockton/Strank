# 編集方法:
#   キー: テキスト
#   - 最初のコロンより左のキーは変更せず、右側の文言だけを変えてください。
#   - {プレースホルダー} はそのまま残してください。文中での位置は動かせます。
#   - .zero / .one / .two / .few / .many / .other で終わるキーは複数形です。
#     必要な形を用意し、必ず .other を含めてください。
#   - # で始まる行はコメントです。改行は \n です。
#   - 空または欠けている文言は英語に戻ります。
