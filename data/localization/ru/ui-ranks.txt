# ---------------------------------------------------- ТЕКСТ STRANK: РАНГИ ---------------------------------------------------------
# Ranks gallery, rank manager, create/edit rank form, and the ranks.txt editor.
#
# Как править:
#   ключ: текст
#   - Не меняйте ключи (слева от первого двоеточия); меняйте только текст.
#   - Оставляйте {плейсхолдеры} как есть. Их можно переставлять в предложении.
#   - Ключи с .zero / .one / .two / .few / .many / .other - формы множественного числа.
#     Используйте нужные вашей языке формы и всегда оставляйте .other.
#   - Строки с # - комментарии. \n - перевод строки.
#   - Пустой или отсутствующий текст берётся из английского.
# --------------------------------------------------------------------------------------------------------------------------------
