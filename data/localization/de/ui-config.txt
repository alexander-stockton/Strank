# So bearbeiten:
#   Schlüssel: Text
#   - Schlüssel links vom ersten Doppelpunkt unverändert lassen; nur den Text ändern.
#   - {Platzhalter} so lassen. Sie dürfen innerhalb des Satzes verschoben werden.
#   - Schlüssel mit .zero / .one / .two / .few / .many / .other sind Pluralformen.
#     Nutzen Sie die Formen Ihrer Sprache und behalten Sie immer .other.
#   - Zeilen mit # sind Kommentare. \n für einen Zeilenumbruch.
#   - Leerer oder fehlender Text fällt auf Englisch zurück.
