#
#   1. Altere apenas NOME DA CLASSIFICAÇÃO #, o caminho da imagem do emblema ou os itens das listas em classificações personalizadas; nunca os rótulos de cabeçalho.
#   2. As imagens dos emblemas ficam em data/badges/  (exemplo: badges/unranked.svg).
#   3. Depois de um hífen, escreva o nome do exercício.
#   4. Tudo o que estiver entre (parênteses) neste arquivo é um campo opcional.
#   5. Se preencher os parênteses em ranks.txt, remova os parênteses.
#   6. Se preencher os parênteses em ranks.txt, inclua todos os campos que estavam dentro deles.
#   7. Tudo o que estiver fora dos parênteses é obrigatório.
#   8. Tudo o que estiver entre [colchetes] neste arquivo é um número; remova os [] depois de inserir o valor.
#   9. Tudo o que estiver entre {chaves} neste arquivo é texto; mantenha as {} depois de inserir o texto.
#  10. As listas podem ter qualquer número de itens (mínimo 1, recomendado 2–3).
#  11. Mantenha a indentação com tabulações intacta; o analisador depende dela.
#  12. Para indicar que não há peso adicional, escreva 0lb (ou a sua unidade) se ainda quiser que o campo de peso apareça durante um treino ativo.
#  13. Para indicar que não há distância, escreva 0mi (ou a sua unidade) se ainda quiser que o campo de distância apareça durante um treino ativo.
#  14. Fique à vontade para adicionar os seus próprios pesos e unidades de peso. Isso não vai quebrar o aplicativo.
#  15. Para indicar que um exercício é feito numa única série de repetições, sem repetir, defina o número de séries como x1.
#  16. Exercícios verticais ou retos são indicados com (I) para a posição de lápis, (L) para a posição dobrada e (T) para os braços estendidos para os lados.
#  17. Em ranks.txt, a posição ou os elementos descritivos entre parênteses antes do peso ou das repetições são adicionados ao nome do exercício.
#  18. Alterar este formato ou as suas regras não modifica em nada o funcionamento do analisador. Estas regras estão fixas no código.
#
