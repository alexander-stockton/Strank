# ---------------------------------------------------- TEXTO DO STRANK: CLASSIFICAÇÕES ---------------------------------------------
# Ranks gallery, rank manager, create/edit rank form, and the ranks.txt editor.
#
# Como editar:
#   chave: texto
#   - Não altere as chaves (à esquerda do primeiro dois-pontos); altere só o texto.
#   - Mantenha os {marcadores} como estão. Pode movê-los na frase.
#   - Chaves que terminam em .zero / .one / .two / .few / .many / .other são plurais.
#     Use as formas da sua língua e inclua sempre .other.
#   - Linhas que começam com # são comentários. Escreva \n para uma quebra de linha.
#   - Texto em falta ou vazio usa o inglês.
# --------------------------------------------------------------------------------------------------------------------------------
