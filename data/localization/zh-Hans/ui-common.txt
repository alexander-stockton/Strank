# Shell, navigation, startup errors, and words shared by several screens.
#
# 如何编辑:
#   键: 文本
#   - 不要改第一个冒号左边的键，只改右边的文字。
#   - 保留 {占位符}，可以在句子里移动它们。
#   - 以 .zero / .one / .two / .few / .many / .other 结尾的键是复数形式。
#     按你的语言需要填写，并始终包含 .other。
#   - 以 # 开头的行是注释。用 \n 表示换行。
#   - 缺失或空白的文本会回退到英语。

# App shell

shell.uiFailed: 界面未能启动

shell.localData.reset: 重置本地数据
