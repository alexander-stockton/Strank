# ---------------------------------------------------- TEXTE STRANK : RANGS --------------------------------------------------------
# Ranks gallery, rank manager, create/edit rank form, and the ranks.txt editor.
#
# Comment modifier :
#   clé: texte
#   - Ne changez pas les clés (à gauche du premier deux-points) ; changez seulement le texte.
#   - Gardez les {marqueurs} tels quels. Vous pouvez les déplacer dans la phrase.
#   - Les clés en .zero / .one / .two / .few / .many / .other sont des formes plurielles.
#     Utilisez celles dont votre langue a besoin et incluez toujours .other.
#   - Les lignes commençant par # sont des commentaires. Écrivez \n pour un saut de ligne.
#   - Un texte manquant ou vide retombe sur l’anglais.
# --------------------------------------------------------------------------------------------------------------------------------
