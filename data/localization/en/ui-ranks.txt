# ---------------------------------------------------- STRANK UI TEXT: RANKS -------------------------------------------------------
# Ranks gallery, rank manager, create/edit rank form, and the ranks.txt editor.
#
# How to edit:
#   key: text
#   - Keep each key (left of the first colon) exactly as it is; change only the text after it.
#   - Keep {placeholders} as written. You may move them within the sentence.
#   - Keys ending in .zero / .one / .two / .few / .many / .other are plural forms of one text.
#     Use the forms your language needs and always include .other.
#   - Lines starting with # are comments. Write \n for a line break.
#   - A missing or empty text falls back to English.
#   - Rank names, exercise names, and headers come from ranks.txt and are never translated here.
# --------------------------------------------------------------------------------------------------------------------------------
