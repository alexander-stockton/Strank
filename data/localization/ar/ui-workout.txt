# طريقة التعديل:
#   المفتاح: النص
#   - لا تغيّر المفاتيح (يسار أول نقطتين)؛ غيّر النص فقط.
#   - أبقِ {العناصر النائبة} كما هي. يمكنك نقلها داخل الجملة.
#   - المفاتيح التي تنتهي بـ .zero / .one / .two / .few / .many / .other صيغ جمع.
#     استخدم الصيغ التي تحتاجها لغتك ودائمًا أدرج .other.
#   - الأسطر التي تبدأ بـ # تعليقات. اكتب \n لسطر جديد.

workout.title: التمرين
workout.empty: لا تمارين متوقعة اليوم.
workout.discard: تجاهل هذا التمرين؟
workout.startFailed: فشل بدء التمرين.
workout.completeFailed: فشل الإكمال.
workout.noActive: لا تمرين نشط.
workout.selectOne: اختر تمرينًا واحدًا على الأقل.
workout.metricsInvalid: المقاييس غير صالحة.
workout.loadExpectationsFailed: فشل تحميل المتطلبات.
